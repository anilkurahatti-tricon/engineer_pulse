# Anil Assistant

This solution contains the Anil chatbot and the `langchain_simple_assistance` implementation.

## Project Components

- `chatbot.py` — Main chatbot application.
- `langchain_simple_assistance` — LangChain-based assistant implementation.
- `requirments.txt` — Python dependency list.

## Setup

Open PowerShell and run:

```powershell
cd Anil
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirments.txt
